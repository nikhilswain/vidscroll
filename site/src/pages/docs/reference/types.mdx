to install. It has three entry points, and each exports only what it needs.

## `vidscroll/element`

Importing this entry registers `<vid-scroll>` and `<vid-scroll-section>`, and
adds them to `HTMLElementTagNameMap`, so `document.querySelector("vid-scroll")`
is typed.

## Two naming details

- The React entry calls the event map `ScrollVideoEvents`; the core entry calls
  it `ScrollVideoEventMap` and includes the `loader` event, which the React
  `api` doesn't list.
- `onLoad` receives `{ source, probe }`. `source` is `"original"`,
  `"optimized"`, `"cache"` or `"stream"`. `probe` describes the file
  (`duration`, `width`, `height`, `frameCount`, `maxKeyframeGap`) and is
  `null` for cached and streamed videos.
