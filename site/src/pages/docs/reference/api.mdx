The api is `null` until the component has mounted (React) or the element has
started. Until the video is ready, methods are safe to call and do nothing,
and `getState` returns zeros.

## Methods

### `on(event, handler)` / `off(event, handler)`

Subscribe to and unsubscribe from [events](#events). Listeners stay attached
for the life of the component, including when the video reloads.

### `getState()`

Returns the [state](#state) right now.

### `isReady()`

`true` once the video is loaded and following the scroll.

### `scrollToTime(seconds, options?)`

Scrolls the page to the position where the video shows `seconds`. `options`
is `{ behavior?: "smooth" | "instant" | "auto" }`, smooth by default. Does
nothing until the video's duration is known, and nothing in `ScrollFrames`.

### `scrollToProgress(progress, options?)`

Scrolls the page to a progress between 0 and 1 (clamped). Same `options`.

### `getSectionProgress(id)`

The section's progress from 0 to 1, the same value as its `--progress`
variable. `0` for unknown ids.

### `addSection(range)` / `removeSection(id)`

Adds or removes a tracked range. `range` is
`{ id, start?, end?, fromTime?, toTime?, fromFrame?, toFrame? }`. Adding an id
that already exists throws. React's `<Section>` and `<vid-scroll-section>` call
these for you.

## State

Returned by `getState()` and passed to `update`, `ready` and `resize` handlers.

<Table>
  <thead>
    <tr><th>Field</th><th>Type</th><th>Meaning</th></tr>
  </thead>
  <tbody>
    <tr><td><code>linearProgress</code></td><td><code>number</code></td><td>Smoothed scroll progress through the block, 0 to 1</td></tr>
    <tr><td><code>time</code></td><td><code>number</code></td><td>Video time in seconds (frame ÷ <code>fps</code> in <code>ScrollFrames</code>)</td></tr>
    <tr><td><code>frameIndex</code></td><td><code>number</code></td><td>Current frame</td></tr>
    <tr><td><code>totalFrames</code></td><td><code>number</code></td><td>Frame count</td></tr>
    <tr><td><code>duration</code></td><td><code>number</code></td><td>Video length in seconds (0 in <code>ScrollFrames</code>)</td></tr>
    <tr><td><code>activeSections</code></td><td><code>string[]</code></td><td>Ids of the active sections</td></tr>
  </tbody>
</Table>

`useScrollVideoState()` returns a simplified version:
`{ ready, progress, time, frame, activeSections }`.

## Events

<Table>
  <thead>
    <tr><th>Event</th><th>Payload</th><th>Fires</th></tr>
  </thead>
  <tbody>
    <tr><td><code>update</code></td><td>state</td><td>Every frame while the video moves, and once when the scroll mapping is rebuilt</td></tr>
    <tr><td><code>ready</code></td><td>state</td><td>The video is ready; again after the scroll mapping is rebuilt</td></tr>
    <tr><td><code>sectionEnter</code></td><td><code>{"{ id, state }"}</code></td><td>A section becomes active</td></tr>
    <tr><td><code>sectionExit</code></td><td><code>{"{ id, state }"}</code></td><td>A section becomes inactive</td></tr>
    <tr><td><code>warmup</code></td><td><code>{"{ value }"}</code></td><td>Progress of the pass over the timeline while loading, 0 to 1</td></tr>
    <tr><td><code>resize</code></td><td>state</td><td>The window is resized</td></tr>
    <tr><td><code>loader</code></td><td>loader state or <code>null</code></td><td>The loading state changes (core and element only)</td></tr>
  </tbody>
</Table>

The scroll mapping is rebuilt when `length`, `fps` or smooth scrolling on/off
changes, or when the video falls back to another copy. Active sections get a
`sectionExit` first, then `sectionEnter` again from the new mapping.

The element also fires DOM events: see
[`<vid-scroll>` events](/docs/without-react/element/#events).
